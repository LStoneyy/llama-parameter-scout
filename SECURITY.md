# Security Policy

## Reporting a Vulnerability

Do **not** file a public GitHub issue to report a security vulnerability.

Please use [GitHub Private Vulnerability Reporting](https://github.com/LStoneyy/llama-parameter-scout/security/advisories/new) instead.

### Scope

We accept reports about vulnerabilities in the source code, dependencies, or published packages. This includes issues such as arbitrary code execution, data exfiltration, or unsafe deserialization.

### Response Expectations

- We aim to acknowledge private vulnerability reports within 72 hours.
- We will work with the reporter to understand and address the issue.
- Once fixed, we will publish a patched release and credit the reporter (unless anonymity is requested).
